# muse-onelaugh1125-entry

Entry for the make.fun competition [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a).

## The entry

> I asked my smart TV to surprise me, so it opened my bank app.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: the laugh is instant and needs no setup — 'surprise me' is a real voice-command phrase, and the bank app is the one result that is both a genuine surprise and a small horror, so the turn lands in a single breath. It is tight enough that removing any word breaks it. The rejected candidates were a plastic-houseplant line whose judgement gag needed a second beat, and a Roomba line that stretched its hiding-from-responsibilities metaphor too far to stay tight.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed line to `entry.txt` (sha256 a49afd8b9d2e2bd8cd8ad583736acbafb4f5ebaba6ad4395f883a118db8846f7), then reads it back and verifies the bytes.
